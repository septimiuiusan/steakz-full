# 🥩 Steakz Restaurant Management System (Monorepo)

Steakz is a full-stack multi-branch restaurant management system built with:

- ⚙️ **Backend:** Node.js, Express, TypeScript, Prisma ORM, PostgreSQL
- 💻 **Frontend:** React, Vite, TypeScript, Tailwind CSS (or CSS modules)
- 🧠 **Database:** PostgreSQL via Prisma
- 🧑‍🤝‍🧑 **Roles:** `ADMIN`, `BRANCH_MANAGER`, `STAFF` (`CHEF`, `CASHIER`), `CUSTOMER`
